## 網站怎麼更新

把最新報告存成根目錄的 `index.html`（檔名不可有空格），推送到 `main` 後，GitHub Pages 會自動重建，約 1–3 分鐘生效。

## 注意

- 首頁檔名必須是 `index.html`，不要加空格或改成中文檔名。
- 更新時覆寫同一個 `index.html`，不要另外上傳 `技術與基本面報告.html`。
- 必須保留 STOCK_META 分類、決策卡市場／次族群徽章、AI 分類面板、交易提示標題格式（市場｜次族群｜名稱）。
